# UI-/Usability-Hilfen (Recherche 2026-10-29)

Stars/Installzahlen stammen von Drittseiten, Lizenzen nicht überall geprüft. Web-Skills (CSS/React) passen nur als Checkliste, nicht als Code (WinForms, keine Fremdpakete). Screenshots mit echten Daten nie an externe Dienste geben, nur erfundene Testdaten.

## Empfehlung (Top 3)
1. **Microsoft Win32 UX Guide + Nielsen-Heuristiken** als Checkliste im Brief für den Prüfer-Agenten (Gruppierung, Fehlertexte "Problem + Lösung", Standardschaltfläche, Tab-Reihenfolge, Hinweise statt Modaldialoge). Kostenlos, kein Risiko.
   - https://learn.microsoft.com/en-us/windows/win32/uxguide/visual-index
   - https://learn.microsoft.com/windows/win32/uxguide/mess-error
   - https://learn.microsoft.com/en-us/windows/win32/uxguide/messages
   - Nielsen-Norman, 10 Usability Heuristics: https://www.nngroup.com/ · https://www.ics.com/uxd/resources/nielsen
2. **Anthropic "Design"-Plugin** (anthropics/knowledge-work-plugins, `design/`; Apache-2.0): design-critique und accessibility-review auf `--shot`-Screenshots (4:3/16:9) mit erfundenen Daten. Nur Skills nutzen, Connectoren (Slack/Gmail/Figma) nicht verbinden.
3. **UX Agent Skills / CUJ-Audit** (Carl Sziebert) oder **ux-review** (NickCrew/Claude-Cortex): Hauptabläufe ("Paket anlegen → übernehmen") durchspielen, Befunde priorisieren. Skill-Text vorher lesen, kein npm/Fremdcode ausführen; nur Checkliste übernehmen.
